Minecraft: Dune 0.5.4 overlay installation
==========================================

Base revision
-------------
This overlay was prepared against the main-branch commit:

1c7edec690b6dcc3ed8610bdb251826a10a666ca

The overlay contains complete copies of every file added or changed for 0.5.4. It does not
delete files and it does not contain build output or local Gradle caches.

Installation
------------
1. Back up or commit any local changes in the target Minecraft-Dune checkout.
2. Confirm that the checkout is based on the revision above, or review the conventional
   Minecraft-Dune-0.5.4.patch before applying to a newer revision.
3. Extract Minecraft-Dune-0.5.4-overlay.zip into the repository root and allow matching
   files to be replaced.
4. Run this from PowerShell:

   .\gradlew.bat clean build

5. The expected mod JAR is:

   build\libs\minecraftdune-0.5.4.jar

Alternative: conventional patch
-------------------------------
From the repository root, apply the sibling patch artifact with:

git apply --check ..\Minecraft-Dune-0.5.4.patch
git apply ..\Minecraft-Dune-0.5.4.patch

The first command is a dry-run compatibility check. If it reports conflicts, do not apply
the patch blindly; review the target checkout's changes first.

In-game surface test
--------------------
The 0.5.4 default is sixteenth-block resolution. Use the following commands to compare the
same morphology and region at all supported output resolutions:

/dune dunes settings surface_resolution whole
/dune dunes settings surface_resolution eighth
/dune dunes settings surface_resolution sixteenth

Regenerate after each change. The 0.5.3 camera and screenshot commands remain available.
