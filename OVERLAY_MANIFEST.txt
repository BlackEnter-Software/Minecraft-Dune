Important testing note
----------------------
Create a new Arrakis Dev world for clean 0.5.10 testing. The generator codec can decode a
missing terrain field using defaults, but already generated chunks always retain their old
terrain.

First checks:
  .\gradlew.bat clean build
  .\gradlew.bat runClient

Then:
  /dune geology profile
  /dune geology sample 900 0
  /dune geology sample 3000 0
  /dune geology sample 4500 0
  /dune geology sample 5500 0
  /dune geology sample 6500 0
