Apply
-----
Copy/extract this overlay into the Minecraft-Dune repository root.

Then run:
  .\gradlew.bat clean build
  .\gradlew.bat runClient

IMPORTANT:
Create a NEW Arrakis Dev world. An existing 0.5.7 save retains the old flat generator in
level.dat and is not a valid native-generation test.

Recommended first test:
  /dune geology generate_initial
  /dune geology generation status
