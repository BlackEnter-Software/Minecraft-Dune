Important generation behavior
-----------------------------
Visible native rock columns now replace the sand/sandstone directly beneath them down to the
existing hard crust. With the current flat layers, stone at Y=44 is found and the formation
is rooted upward from Y=45.

Normal sand-only columns are not modified.

Testing
-------
Apply over the current main checkout, then:

  .\gradlew.bat clean build
  .\gradlew.bat runClient

Create a new Arrakis Dev world for clean terrain comparison.

Useful:
  /dune geology profile
  /dune geology sample 1600 0
  /dune geology sample 2000 0
